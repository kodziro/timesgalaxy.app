Privacy

Last updated: 17 October 2026 · free beta

Short version: your child's name, answers and progress stay on your device. We do not get them. There is no account, no cookies and no ads. We count anonymous events, like “a mission was finished”, to learn if the game works.

What is saved, and where

  • The child's first name (typed by a grown-up in the settings), the settings, every answer and the progress are saved only on your device, in your browser's storage (local storage and IndexedDB).
  • They are never uploaded. We have no server that could receive them.
  • The files of the game itself (pages, fonts, icons) are also saved in your browser, so the game works without internet. They hold no personal data.

The save code

  • In the grown-ups area you can copy a save code. It is your backup: it holds the progress, the settings and the child's first name.
  • The code is made on your device and only goes where you paste it. Keep it like a password, for example in your own notes.

Zib's voice

  • Zib speaks with the speech voices of your device. The game picks a voice that runs on the device, so the spoken words are not sent to a speech service.
  • If your browser has no such voice, Zib still speaks, but says “pilot” instead of the child's name.

What we do not do

  • No account and no sign-up. We never ask for an email address.
  • No cookies, so there is no cookie banner.
  • No ads and no ad networks. Nothing follows you to other sites.
  • The child's name, the answers typed in the game and the save code are never sent anywhere.
  • The fonts and pictures come from this site, not from other sites.

Usage counts

We count anonymous events in the game to learn if it works for children: do they finish a mission, do they come back the next day. For this we use TelemetryDeck, a privacy-focused analytics service. Its code is a file on this site, and it sets no cookies. The home page sends one event when it opens (“home page opened”) with only the general details in the list below and a random code that is made new each time and never saved. This privacy page sends nothing.

What is sent:

  • The name of the event, for example “first flight finished”, “mission finished”, “planet challenge passed”, “came back on day 7”, “grown-ups area opened”, “save code copied”, “rating given”.
  • A few numbers and fixed names with some events: how many planets the first flight found, how many questions a mission had, how many new facts it showed, which planet (a times table, like “6”), how many tries a challenge took, the day number since the first use, the streak, the question number where the child stopped, and which item was bought in the Hangar with its crystal price.
  • Ratings: on days 2, 7 and 14 your child can tap one of three faces after a mission, and in the grown-ups area you can give 1 to 5 stars and tap one fixed word (“too easy”, “too hard” or “wants to play again”). We get only that number, the word you tapped and the day number. There is no text field.
  • With every event: the type of device (iPad, iPhone, Android or computer), whether the game was opened from the Home Screen, and that this is the free beta.
  • A random code made by the game on your device the first time it starts. It lets us count how many devices play, without knowing who. It is scrambled again (hashed) before it is sent, and TelemetryDeck stores only the scrambled form. “Reset this child” keeps it.
  • What every browser sends with a web request: your browser and system version.

What is never sent: the child's name, the answers, anything typed, the save code.

When there is no internet, the events wait on your device and are sent later.

Like any web request, these events reach TelemetryDeck from your IP address. TelemetryDeck uses the first part of it to guess the country and says it never stores IP addresses. We never see your IP address. TelemetryDeck rounds the time of each event to the hour and keeps the data on servers in Germany and the Netherlands.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub may log technical data such as your IP address when a page loads. We do not use that data.

Children

The game is set up by a grown-up and played by a child. We do not collect personal data from children or from grown-ups. The game screens have no links to other sites. The grown-ups area opens only when you press and hold the lock.

Deleting the data

Everything is in your browser, so you are in control. In the grown-ups area, “Reset this child” deletes the progress. Clearing this site's data in your browser settings deletes everything.
